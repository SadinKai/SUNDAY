# Support

Choose the channel that matches the request:

- **Bug:** open the GitHub bug form with sanitized reproduction steps.
- **Feature request:** use the feature request form and describe the underlying
  problem before proposing implementation details.
- **Usage or build question:** check the README and `docs/` first, then open a
  bug report only when documented behavior is reproducibly incorrect.
- **Security issue:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Contribution:** read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull
  request.

Support is community-maintained and no response time is guaranteed. Never post
Roblox cookies, account records, passwords, tokens, signing material, local
databases, or unredacted personal paths. This project cannot provide Roblox
account recovery, moderation appeals, or platform support.
