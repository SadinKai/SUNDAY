# Accounts and sign-in

SUNDAY stores the accounts you add on this Windows PC so you can select them
from the Launch screen.

## Add an account

1. Open **Accounts**.
2. Select **Add account**.
3. Sign in on the Roblox page opened by SUNDAY.
4. Return to SUNDAY after the account appears in the roster.

The sign-in window is a temporary, origin-restricted WebView for
`www.roblox.com`. SUNDAY imports the resulting Roblox session, protects it with
Windows DPAPI for the current Windows user, purges the WebView cookie, and
removes the temporary profile on a best-effort basis.

SUNDAY does not show raw Roblox cookies in the interface. Read
[Privacy](../../PRIVACY.md) for the exact storage and network boundary.

## Refresh or remove an account

- Use **Refresh** when an avatar, presence, or public profile field is stale.
- Use **Sign in again** when SUNDAY reports that the Roblox session expired.
- Use **Remove** to delete that saved account record from SUNDAY.

Never paste a Roblox cookie into an issue, screenshot, log excerpt, or support
message.
