## Known limitations

- SUNDAY-authored Windows binaries are unsigned. Hashes prove bytes, not
  publisher identity or SmartScreen reputation.
- Automatic update application is unavailable; users update manually from the
  canonical GitHub Releases page.
- Legacy multi-instance mode supports verified classic Win32 Roblox only.
  Store/AppX Roblox is detected but is not eligible for clone-based isolation.
- Four real clients were qualified. The six-client allocator and behavior have
  deterministic/synthetic coverage, but E and F were not live-qualified.
- Roblox or Windows changes can invalidate the legacy singleton, filesystem,
  process, or launch behavior after this artifact-specific qualification.
- The installer was structurally extracted and audited but not installed or
  uninstalled on a disposable Windows profile in this release audit.
- Exact bit-for-bit source reproducibility of the Tauri PE was not demonstrated.
