## Repairs

Startup ownership now requires the original process creation identity,
canonical executable path, and file identity, including the final capability
issuance check and restoration after application restart. Missing executable
errors have a listener before PID validation. Partial launch responses clear
successful selections, and successive retries contain only remaining failures.
Custom Roblox installations survive defaults migration as verified discovery
evidence while newer compatible installations can still win automatic ranking.

The production runtime uses an explicit 39-module allowlist. Recovery core code
and private approvals are excluded from binaries; machine-specific recovery
paths, fingerprints, and target inventories were removed from public source
and preserved privately. The secret scanner now checks escaped Windows paths.

The Windows CI Rust steps stop on any native command failure, preventing a
later passing command from hiding an earlier failed check. CI is enabled for
the proposed `release/v1.8.19` branch as well as main and pull requests.

The first live attempt exposed a harness error involving MSIX filesystem path
virtualization. That attempt was stopped before the second account launched.
The test-created process was independently matched to its original spawn
fingerprint and its exit was confirmed. No foreign process was adopted or
terminated. The interrupted launch record was reconciled through normal
application startup, without a direct repair transaction.

Closing during startup also exposed a product shutdown defect: the database
could close before launch compensation completed. Shutdown now rejects new
launches, drains cancellation of active launches, and preserves completed
clients. Both cancellation and completed-client preservation have regressions.
The shell grants bounded compensation time before forcing backend exit.

The Rust advisory scanner reports upstream maintenance warnings, a yanked

not publisher identity. The manifest qualification uses a synthetic local key
and does not activate automatic updating or create a public signing claim.
